# Wallet Visual Library v2 – Frontend

The Wallet screen is optimized around the inspiration collection. Capture is moved to a focused dialog. The view supports grid/list display, filtering, sorting, search, original-source navigation and secondary management actions.

The recipe handoff pre-fills the existing recipe-create screen. The Food-Moment handoff returns to Intent Home with the Wallet inspiration as editable intent context; it does not create Food-Moment domain data directly.
