# Wallet V3 – Content-first & Workspace Sharing

- Mobile/desktop Wallet toolbar reduced to Search, Filter and View switch.
- Search expands only when needed; filters and sorting live in a dedicated dialog/bottom sheet.
- Mobile grid uses two compact image tiles where space permits.
- Workspace sharing follows the existing recipe assignment principle.
- Shared Wallet items remain a single object; no copies are created.
- Only the creator manages sharing, edits and deletion. Recipients may open the source and derive their own Recipe/Food Moment context.
